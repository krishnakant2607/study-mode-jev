# FocusMaxx hackathon demo

## Prepare

1. Reload the installed extension and YouTube tabs after rebuilding. Confirm Chrome displays FocusMaxx v0.2.0.
2. Enter your TypeSafe key privately in Settings and Test connection. Pin a model only after testing it.
3. Enable FocusMaxx with blank preferences. Check the real NeuralNine channel: useful framework/cloud courses should remain visible, without requiring the title to say Python. Confirm uncertain content is preserved and no clickbait control exists.
4. Save a positive preference such as wildlife documentaries and snake observations, plus a negative preference for music videos. Confirm actual matching content behaves as intended; metadata judgments need calibration.
5. Check Shorts on home/search/channel pages and in the vertical viewer. Useful Shorts should remain; clearly unwanted ones should be covered and their player paused. YouTube experiments may use unrecognized renderers.
6. Open Rehearse demo and keep it available as an explicitly labelled offline backup.

## Present

- Show Balanced mode: only high-confidence entertainment is covered; useful and uncertain content stays.
- Show Preferences: allow wildlife observations, hide music videos, Save. Explicit exclusions win conflicts.
- Show a retained snake observation and a covered music video. If using rehearsal, identify the judgments as authored immediately.
- Show individual Shorts filtering and the real session counts. Never call them time saved.
- Explain Jev's role: three typed judgments from bounded metadata; code handles priority and display.

## Recover

API outages leave videos visible and show a connection warning. Retry after recovery, or switch to the labelled offline rehearsal. Authentication errors require a valid key in private Settings. Reload existing YouTube tabs after an extension reload. Use a dated recording of a validated live flow if the site's current layout fails; do not claim fixture tests prove live coverage.

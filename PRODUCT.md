# FocusMaxx
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
TypeScript, HTML/CSS, esbuild and Chrome Manifest V3. Jev supplies typed decisions through the official TypeSafe HTTP API.

## Users
People browsing YouTube intentionally for useful information, work, research or learning. This build is not a parental-control product.

## Product Purpose
Cover clearly unwanted entertainment while preserving useful and ambiguous content. Let users define positive and negative preferences; keep keyword chips as optional interest hints.

## Capabilities and Constraints
Balanced default covers entertainment only at a Jev judgment of 0.90 or greater. Explicit negative matches at 0.90 take precedence, then explicit positive matches at 0.90 override entertainment. Uncertain metadata and evaluation failures remain visible. Clickbait has no scoring question or blocking rule. Shorts are evaluated individually across recognized card layouts and an active vertical viewer; blocked player media is paused. Text metadata and channel-page context are used, not images or transcripts. Unrecognized YouTube experiments remain outside verified coverage.

## Brand Commitments
User chose the name FocusMaxx and a premium, clean, sophisticated panel. The established charcoal/orange references remain visual authority. Controls lead; factual session outcomes support them.

## Evidence on Hand
User supplied a NeuralNine page showing useful content blocked as uncertain. Authored fixtures now test framework courses, cloud tutorials, dramatic educational titles, wildlife preferences, Shorts and visible uncertainty. No measured live Jev accuracy or user-profile compatibility benchmark exists.

## Product Principles
Preserve useful content. Personal preferences override generic categories, with explicit exclusions winning conflicts. Never make keywords a literal gate. Keep failures visible and recovery clear. Separate live and authored rehearsal. Keep credentials private and analytics factual.
